# fireproximityprompt: (ProximityPrompt: ProximityPrompt) -> ()
Triggers a ProximityPrompt as if the player used it.
```lua
local ProximityPrompt = workspace.Door.ProximityPrompt
fireproximityprompt(ProximityPrompt)
```
