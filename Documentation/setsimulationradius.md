# setsimulationradius: (Radius: number, MaximumRadius: number?) -> ()
Sets how far around the player their client simulates physics, and optionally the maximum for that distance.
```lua
setsimulationradius(1000, 1000)
```

| :- |
| set_simulation_radius |

| :-------- | :------- |
| MaximumRadius: [number?](https://create.roblox.com/docs/luau/numbers) | The maximum simulation radius. |
