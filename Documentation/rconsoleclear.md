# rconsoleclear: () -> ()
Clears all the text in the executor's console window.
```lua
rconsolecreate()
rconsoleprint("Hello world!")
rconsoleclear()
```
# Aliases
| Name |
| :- |
| consoleclear |

# Test requirements
To pass the rconsoleclear test, the function must:
- Clear a console opened with [rconsolecreate](rconsolecreate.md) without erroring.
